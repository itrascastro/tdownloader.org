Installer sous Windows #

À l’ouverture de l’installateur, Windows affiche un avertissement bleu SmartScreen. C’est tout à fait normal : il apparaît pour toute nouvelle application qui n’a pas encore de certificat de signature payant. L’app est sûre ; il suffit de dire à Windows de continuer.

  1. Double-clique sur le fichier tdownloader-setup.exe que tu as téléchargé.

  2. L’écran bleu Windows protected your PC (« Windows a protégé votre ordinateur ») apparaît. Clique sur le lien More info (Plus d’informations).

  3. Le nom de l’app s’affiche et un nouveau bouton apparaît. Clique sur Run anyway (Exécuter quand même).

  4. Poursuis l’installation normalement et ouvre tdownloader.

La première fois que tu ouvres l’app, elle peut mettre quelques secondes à afficher tes canaux pendant que Windows l’analyse. Si le panneau latéral est vide, patiente un instant : il se remplit tout seul dès que le programme a fini de démarrer.
Pour mettre à jour, ne téléchargez pas l'installateur à nouveau. Ouvrez tdownloader et, si une nouvelle version est disponible, il se met à jour tout seul au démarrage : il vous prévient et redémarre déjà sur la dernière version. Réinstaller par-dessus à la main n'est pas nécessaire.

Installer sous macOS #

macOS peut indiquer que l’app est endommagée et ne peut pas être ouverte (ou qu’elle provient d’un développeur non identifié). Elle n’est pas endommagée : c’est la protection Gatekeeper qui bloque les apps sans signature payante d’Apple. Cela se règle en 10 secondes.

  1. Glisse tdownloader dans ton dossier Applications. Dans l’alerte, clique sur Cancel (PAS Move to Trash).

  2. Ouvre l’app Terminal (dans Applications → Utilitaires, ou via Spotlight : Cmd+Espace et tape Terminal). Colle cette commande et appuie sur Entrée :

    xattr -dr com.apple.quarantine /Applications/tdownloader.app

    Elle retire la marque de quarantaine que macOS ajoute aux téléchargements. Aucun mot de passe demandé et, si tout va bien, aucun message.

  3. Ouvre tdownloader normalement (double-clic). Il ne se plaindra plus.

Si au lieu de « endommagée » il indique seulement développeur non identifié, fais un clic droit (ou Control+clic) sur l’app → Ouvrir → Ouvrir. Seulement la première fois.
Pour mettre à jour, ouvrez l'app : elle se met à jour toute seule au démarrage et redémarre sur la dernière version. Ne copiez pas le nouveau .dmg par-dessus à la main, car vous repasseriez par la quarantaine de Gatekeeper et devriez répéter l'étape de la commande xattr ci-dessus.

Installer sous Linux #

Il y a deux formats. Utilise celui que tu préfères.

Paquet .deb Ubuntu, Debian, Mint...

Double-clique sur le fichier pour l’installer depuis la logithèque, ou depuis un terminal :

sudo apt install ./tdownloader_*.deb

AppImage toute distribution

L’AppImage ne nécessite aucune installation : rends-le exécutable et ouvre-le.

  1. Clic droit sur le fichier → Propriétés → Permissions → coche Autoriser l’exécution comme un programme. Ou en terminal :

    chmod +x tdownloader-*.AppImage

  2. Double-clique pour l’ouvrir.

Créer ton API ID et ton API Hash #

Telegram exige des identifiants personnels (un API ID et un API Hash) pour que les apps accèdent à ton compte. Ils se créent une seule fois, sont gratuits et prennent une minute. La page de Telegram est en anglais ; voici chaque étape avec sa capture.

Ouvrir my.telegram.org

  1. Va sur my.telegram.org. Saisis ton numéro de téléphone au format international (avec l’indicatif du pays, par exemple +34611223344) et clique sur Next.

  2. Telegram envoie un code de connexion dans ton app Telegram (PAS par SMS). Ouvre Telegram sur ton téléphone ou ton ordinateur : dans le chat officiel Telegram, tu verras un message avec ton Web login code.

  3. Reviens sur my.telegram.org, saisis ce code dans Confirmation code et clique sur Sign In.

  4. Clique sur API development tools.

  5. Remplis le formulaire Create new application avec ces valeurs et clique sur Create application :

    App title
    tdownloader
    Short name
    tdownloader (de 5 à 32 lettres ou chiffres)
    URL
    Laisse vide
    Platform
    Choisis Desktop
    Description
    tdownloader app (ou laisse vide)

  6. Tu verras deux valeurs : App api_id (un nombre) et App api_hash (une longue chaîne de lettres et de chiffres). Copie les deux. Ce sont les seules dont tu as besoin.

  7. Reviens dans tdownloader : colle l’api_id dans le champ API ID et l’api_hash dans API Hash, ajoute ton téléphone et clique sur Envoyer le code. C’est fait !

Ces identifiants sont les tiens et restent sur ton ordinateur. tdownloader ne les envoie jamais à nos serveurs : ils connectent ton appareil directement à Telegram, comme l’app officielle.
