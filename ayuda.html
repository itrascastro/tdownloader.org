Instalar en Windows #

Al abrir el instalador, Windows puede mostrar un aviso azul de SmartScreen ("Windows protegio tu PC"). Es normal con cualquier aplicacion nueva que aun no tiene un certificado de firma de pago. La app es segura.

  1. Ejecuta el archivo tdownloader-setup.exe que descargaste.

  2. Si aparece el aviso azul, pulsa en Mas informacion.

  3. Pulsa el boton Ejecutar de todos modos.

  4. Sigue el instalador con normalidad y abre tdownloader.

La primera vez que abras la app puede tardar unos segundos en mostrar tus canales mientras Windows la analiza. Si el panel lateral aparece vacio, espera un momento: se completa solo en cuanto el programa termina de arrancar.

Instalar en macOS #

macOS puede decir que la app es de un desarrollador no identificado, o incluso que "esta danada y no se puede abrir". No esta danada: es la proteccion Gatekeeper bloqueando apps que aun no tienen la firma de pago de Apple.

  1. Arrastra tdownloader a tu carpeta de Aplicaciones.

  2. Haz clic derecho (o Control + clic) sobre la app y elige Abrir.

  3. En el dialogo que aparece, pulsa de nuevo Abrir. Solo hay que hacerlo la primera vez.

Si sigue diciendo que esta "danada"

Abre la app Terminal y ejecuta este comando (ajusta la ruta si la instalaste en otro sitio):

xattr -dr com.apple.quarantine /Applications/tdownloader.app

Despues abre la app con normalidad.

Instalar en Linux #

Hay dos formatos. Usa el que prefieras.

Paquete .deb Ubuntu, Debian, Mint...

Haz doble clic en el archivo para instalarlo desde el Centro de Software, o desde una terminal:

sudo apt install ./tdownloader_*.deb

AppImage cualquier distribucion

El AppImage no necesita instalacion: solo dale permiso de ejecucion y abrelo.

  1. Clic derecho sobre el archivo → Propiedades → Permisos → marca Permitir ejecutar como un programa. O por terminal:

    chmod +x tdownloader-*.AppImage

  2. Haz doble clic para abrirlo.

Crear tu API ID y API Hash #

Telegram exige unas credenciales personales (un API ID y un API Hash) para que las aplicaciones accedan a tu cuenta. Se crean una sola vez, son gratis y tardan un minuto.

  1. Entra en my.telegram.org.

  2. Inicia sesion con tu numero de telefono (el mismo de tu cuenta de Telegram, con prefijo internacional). Telegram te enviara un codigo dentro de la app de Telegram; introducelo.

  3. Pulsa en API development tools.

  4. Rellena el formulario Create new application:

    App title
    Un nombre cualquiera, por ejemplo tdownloader.
    Short name
    Por ejemplo tdownloader (entre 5 y 32 letras o numeros).
    URL
    Dejalo en blanco.
    Platform
    Elige Desktop.
    Description
    Opcional, dejalo en blanco.

  5. Pulsa Create application.

  6. Veras dos valores: App api_id (un numero) y App api_hash (una cadena larga). Copialos.

  7. Vuelve a tdownloader, pega el api_id en API ID y el api_hash en API Hash, anade tu telefono y pulsa Enviar codigo.

Estas credenciales son tuyas y se quedan en tu ordenador. tdownloader nunca las envia a nuestros servidores: solo conectan tu equipo directamente con Telegram, igual que la app oficial.
