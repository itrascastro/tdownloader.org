Instalar en Windows

Al abrir el instalador, Windows puede mostrar un aviso azul de SmartScreen que dice "Windows protegio tu PC". Esto es normal: aparece con cualquier aplicacion nueva que todavia no tiene un certificado de firma de pago. La app es segura.

  1. Ejecuta el archivo tdownloader-setup.exe que has descargado.
  2. Si aparece el aviso azul, pulsa en Mas informacion.
  3. Aparecera un boton Ejecutar de todos modos. Pulsalo.
  4. Sigue el instalador con normalidad y abre tdownloader.
La primera vez que abras la app puede tardar unos segundos en mostrar tus canales (Windows analiza la aplicacion la primera vez). Si el panel lateral aparece vacio, espera un momento: se completa solo en cuanto el programa termina de arrancar.

Instalar en macOS

macOS puede decir que la app es de un desarrollador no identificado o incluso que "esta danada y no se puede abrir". No esta danada: es la proteccion Gatekeeper bloqueando apps que aun no tienen la firma de pago de Apple.

  1. Arrastra tdownloader a tu carpeta de Aplicaciones.
  2. Haz clic derecho (o Control + clic) sobre la app y elige Abrir.
  3. En el dialogo que aparece, pulsa de nuevo Abrir. Solo hay que hacerlo la primera vez.

Si sigue diciendo que esta "danada"

Abre la app Terminal y pega este comando (ajusta la ruta si instalaste en otro sitio):

xattr -dr com.apple.quarantine /Applications/tdownloader.app

Despues abre la app con normalidad.

Instalar en Linux

Hay dos formatos. Usa el que prefieras:

Paquete .deb (Ubuntu, Debian, Mint...)

Haz doble clic en el archivo .deb para instalarlo desde el Centro de Software, o desde una terminal:

sudo apt install ./tdownloader_*.deb

AppImage (cualquier distribucion)

El AppImage no necesita instalacion. Solo dale permiso de ejecucion y abrelo:

  1. Clic derecho sobre el archivo → Propiedades → Permisos → marca Permitir ejecutar el archivo como un programa. O por terminal: 
    chmod +x tdownloader-*.AppImage
  2. Haz doble clic para abrirlo.

Crear tu API ID y API Hash

Telegram exige unas credenciales personales (un API ID y un API Hash) para que las aplicaciones accedan a tu cuenta. Se crean una sola vez, son gratis y tardan un minuto.

  1. Entra en my.telegram.org.
  2. Inicia sesion con tu numero de telefono (el mismo de tu cuenta de Telegram, con prefijo internacional). Telegram te enviara un codigo dentro de la app de Telegram; introducelo.
  3. Pulsa en API development tools.
  4. Rellena el formulario Create new application:
    • App title: un nombre cualquiera, por ejemplo tdownloader.
    • Short name: por ejemplo tdownloader (entre 5 y 32 letras o numeros).
    • URL: dejalo en blanco.
    • Platform: elige Desktop.
    • Description: opcional, dejalo en blanco.
  5. Pulsa Create application.
  6. Veras dos valores: App api_id (un numero) y App api_hash (una cadena larga de letras y numeros). Copialos.
  7. Vuelve a tdownloader y pega el api_id en el campo API ID y el api_hash en el campo API Hash. Anade tu telefono y pulsa Enviar codigo.
Estas credenciales son tuyas y se quedan en tu ordenador. tdownloader nunca las envia a nuestros servidores: se usan solo para conectar tu equipo directamente con Telegram, igual que la app oficial.
