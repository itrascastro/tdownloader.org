Instalar no Windows #

Ao abrir o instalador, o Windows mostra um aviso azul do SmartScreen. É completamente normal: aparece em qualquer aplicação nova que ainda não tem um certificado de assinatura pago. A app é segura; basta dizer ao Windows que continue.

  1. Faz duplo clique no ficheiro TDownloader-setup.exe que descarregaste.

  2. Aparece o ecrã azul Windows protected your PC (o Windows protegeu o seu PC). Clica na ligação More info (Mais informações).

  3. É mostrado o nome da app e surge um botão novo. Clica em Run anyway (Executar mesmo assim).

  4. Continua o instalador normalmente e abre o TDownloader.

Na primeira vez que abrires a app pode demorar uns segundos a mostrar os teus canais enquanto o Windows a analisa. Se o painel lateral aparecer vazio, espera um momento: preenche-se sozinho assim que o programa acaba de arrancar.
Para atualizar, não descarregue o instalador novamente. Abre o TDownloader e, se houver uma versão nova, atualiza-se sozinho ao arrancar: avisa-te e reinicia já com a versão mais recente. Reinstalar por cima manualmente não é necessário.

Instalar no macOS #

O macOS pode dizer que a app está danificada e não pode ser aberta (ou que é de um programador não identificado). Não está danificada: é a proteção Gatekeeper a bloquear apps que ainda não têm a assinatura paga da Apple. Resolve-se em 10 segundos.

  1. Arrasta o TDownloader para a tua pasta Aplicações. No aviso, clica em Cancel (NÃO Move to Trash).

  2. Abre a app Terminal (em Aplicações → Utilitários, ou pelo Spotlight: Cmd+Espaço e escreve Terminal). Cola este comando e carrega em Enter:

    xattr -dr com.apple.quarantine /Applications/tdownloader.app

    Remove a marca de quarentena que o macOS põe no que é descarregado. Não pede palavra-passe e, se correr bem, não mostra nenhuma mensagem.

  3. Abre o TDownloader normalmente (duplo clique). Já não se vai queixar.

Se em vez de danificada disser apenas programador não identificado, basta fazer clique direito (ou Control+clique) na app → Abrir → Abrir. Só na primeira vez.
Para atualizar, abre a app: atualiza-se sozinha ao arrancar e reinicia com a versão mais recente. Não copies o novo .dmg por cima manualmente, porque voltarias a passar pela quarentena do Gatekeeper e terias de repetir o passo do comando xattr acima.

Instalar no Linux #

Há dois formatos. Usa o que preferires.

Pacote .deb Ubuntu, Debian, Mint...

Faz duplo clique no ficheiro para o instalar a partir do Centro de Software, ou por um terminal:

sudo apt install ./tdownloader_*.deb

AppImage qualquer distribuição

O AppImage não precisa de instalação: dá-lhe permissão de execução e abre-o.

  1. Clique direito no ficheiro → Propriedades → Permissões → ativa Permitir executar como um programa. Ou por terminal:

    chmod +x TDownloader-*.AppImage

  2. Faz duplo clique para o abrir.

Criar o teu API ID e API Hash #

O Telegram exige credenciais pessoais (um API ID e um API Hash) para que as apps acedam à tua conta. Criam-se uma só vez, são grátis e demoram um minuto. A página do Telegram está em inglês; aqui tens cada passo com a sua captura.

Abrir my.telegram.org

  1. Entra em my.telegram.org. Escreve o teu número de telefone em formato internacional (com o indicativo do país, por exemplo +34611223344) e clica em Next.

  2. O Telegram envia um código de acesso para a tua app do Telegram (NÃO por SMS). Abre o Telegram no telemóvel ou no computador: no chat oficial Telegram verás uma mensagem com o teu Web login code.

  3. Volta a my.telegram.org, escreve esse código em Confirmation code e clica em Sign In.

  4. Clica em API development tools.

  5. Preenche o formulário Create new application com estes valores e clica em Create application:

    App title
    TDownloader
    Short name
    TDownloader (entre 5 e 32 letras ou números)
    URL
    Deixa em branco
    Platform
    Escolhe Desktop
    Description
    TDownloader app (ou deixa em branco)

  6. Verás dois valores: App api_id (um número) e App api_hash (uma cadeia longa de letras e números). Copia os dois. São os únicos de que precisas.

  7. Volta ao TDownloader: cola o api_id no campo API ID e o api_hash em API Hash, adiciona o teu telefone e clica em Enviar código. Pronto!

Estas credenciais são tuas e ficam no teu computador. O TDownloader nunca as envia para os nossos servidores: apenas ligam o teu equipamento diretamente ao Telegram, tal como a app oficial.
