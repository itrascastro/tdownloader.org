2. Descripción del servicio

tdownloader es una aplicación de escritorio que facilita la descarga de archivos de canales de Telegram a los que el usuario tiene acceso con su propia cuenta. La aplicación actúa como cliente de la API de Telegram.

El usuario es el único responsable del uso que haga de la aplicación y del contenido que descargue. Queda expresamente prohibido usar tdownloader para:
